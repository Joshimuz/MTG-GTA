# Fantasy fan made Grand Theft Auto set for Magic The Gathering
Everyone loves Universes beyond right? What if there was more ill-fitting series for it!

This is a fan made project, initialy focusing on San Andreas universe commander decks, made within the MagicSetEditor program.

To see all the cards go to the "Card Images" folder. Inside will be all the cards made, including many placeholder and unfinished ones!

Below is a basic overview/design document for the set as a whole, including overaching themes and individual decks and their themes.

## Grove Street Families... and Friends! (San Andreas "Good Guys" deck/"CJ Deck")
v1 of the deck was far too weak in general.
The current v2 of the deck has too many different themes, many of which clash with each other, which leads to poor play patterns (yet to be tested with v2).

Deck is Red Green White.

### Deck Themes
#### Respect
A feature unique to SA (and GTA 2). Respect is a stat in the game which goes up through doing various things and controls how many gang members you can recruit.
Represented here as a counter the player has, similar to experience or energy. Inherits the problem of those too where it's uninteractable which needs to be carefuly managed.

#### Gangs
Grove Street is a gang obviously, but there are many others throughout SA.
Used mechanically as token gangster creatues which you get more of the more respect you have through the "Recruit" mechanic.

#### Vehicles
vroom vroom

#### Missions
Mission cards should be in a seperate deck, similar to how Attractions work in Unfinity.
Have a "Start A Mission" mechanic which draws a random(?) mission which enters like an attraction (but you can only have one?)
Have cards that care about missions being passed. Missions should give respect.
Missions should do what they do in game, present a series of challenges that when overcome give rewards such a money, respect and assets. Working similar to cases in Karlov Manor, but sometimes being double sided with the reward asset on the back. 

#### Gang Territories
Using the Battle card type, but not a Siege, instead it's a Territory.
Territories aren't given to an opponent, but instead start on the owner's side.
When killed, instead of flipping and returning to owner, get given to the killer for them to defend.
